# Nap Cats: Logic Rooms (PROTOTYPE - NOT FOR PRODUCTION)

Playable ad + concept test for a cat logic puzzle in the Queens / star-battle family.

**Status:** in-progress

## Why this game

- Reference market signal: **Meowdoku!** jumped 5 places to **#5 worldwide downloads in Oct 2026** (Sensor Tower), the fastest-rising casual title in the top 10.
- Mechanic studied, product made our own: name, cat art (drawn in code), rooms theme, levels generated by our own algorithm. Nothing copied from the original.

## Hypotheses

- **H1 (instant read):** players get the rule in under 5 s from the hand hint + one-line rule, no text tutorial.
- **H2 (ad hook):** "Level 3: 99% fail" + a fail on camera drives CTR on a cozy/cat audience.
- **H3 (content scale):** a generator + uniqueness solver produces unlimited levels, so content cost is near zero.

## Mechanic

- N x N board split into N colored rooms. Place exactly one cat per row, per column and per room; cats may not touch, even diagonally.
- Tap a cell to place a cat. Correct: the cat curls up, its row, column, neighbours and room get auto-marked. Wrong: red X, lose a heart. 3 hearts.
- HINT button (stands in for a rewarded ad in the full game). 3 levels (5x5, 6x6, 7x7), then end card with PLAY FREE (`mraid.open` when present).
- Levels: random no-touch permutation, rooms grown by flood fill, then hill-climb on room borders until the solver finds exactly one solution.

## Run

```bash
cd prototypes/game-puzzle-research/nap-cats
python3 -m http.server 8771   # http://localhost:8771
```

Flags: `?demo=1` scripted autoplay, `?cap=1` manual clock (`window.__advance(dt)`) for frame-exact ad capture.
Debug: `__game.state`, `__game.solve()`, `__game.level(n)`, `__events` (tap log).

Public demo: https://ketchsoft.github.io/orbit-lock/nap-cats/ (ad video: https://ketchsoft.github.io/orbit-lock/nap-cats/ad-23s.mp4).
Ad project: `production/marketing/nap-cats-ads/` (HyperFrames, `python3 build_ad.py` then render).
